# KBL Manager

Football Manager · NBA2K 마이GM 스타일의 **KBL(한국프로농구) 매니저 게임**입니다.
2026-27 시즌부터 시작해 내가 고른 팀의 전술·출전시간·훈련·계약을 직접 관리하고,
나머지 9개 팀은 실제 감독 성향에 따라 AI가 운영합니다.

## 실행 방법

필요한 것: Node.js 22+, PostgreSQL 16

```bash
# 1) DB 생성 (기본 접속 정보: kbl_app / devpassword @ localhost:5432 / kbl_manager)
#    다른 값을 쓰려면 PGHOST, PGPORT, PGUSER, PGPASSWORD, PGDATABASE 환경변수로 지정
createdb kbl_manager

# 2) 마이그레이션
cd packages/db
npm install
DATABASE_URL=postgres://kbl_app:devpassword@localhost:5432/kbl_manager npm run migrate:up

# 3) API 서버 (http://localhost:4000)
cd ../../apps/server
npm install
npm run seed      # 2026-27 시즌 새 게임 생성
npm start

# 4) 웹 (http://localhost:5173)
cd ../web
npm install
npm run dev
```

웹에서 **🔄 새 게임** → 운영할 팀을 고르면 시작됩니다 (기존 세이브는 초기화).

| 명령 (apps/server) | 설명 |
|---|---|
| `npm start` / `npm run dev` | API 서버 실행 (dev는 파일 변경 시 자동 재시작) |
| `npm run seed` | 새 게임 생성 |
| `npm run simulate` | 한 시즌 → 플레이오프 → 비시즌 → 다음 시즌 시작까지 자동 진행해 결과 출력 (검증용) |
| `npm run simulate -- --live` | 우리 팀 경기를 직접 지휘 모드(구간 진행)로 치르며 시뮬레이션 |
| `npm run simulate -- --stop-at-offseason` | 비시즌 시작 직후에서 멈춤 |
| `npm run typecheck` | 타입 검사 |

## 게임 방법

1. **메인** — 내 팀 성적·순위·감독·샐러리캡·다음 경기·핵심 선수, 팀 순위, 개인 순위(득점·리바운드·어시스트·스틸·블록·3점)
2. **오늘** — 한 번 진행할 때마다 하루가 지나갑니다.
   - **경기일**: 상대 전력을 보고 게임플랜(템포, 3점 비중, 맨투맨/지역방어/압박, 상대 에이스 더블팀, 리바운드 강조)을 정한 뒤
     **경기 직접 지휘** 또는 **빠른 시뮬레이션**
   - **경기 없는 날**: 휴식(피로 회복) 또는 훈련(초점 7종 × 강도 3단계). "다음 경기일까지"로 빠르게 넘길 수 있음
3. **경기 직접 지휘** — 5분마다 작전타임: 코트 위 5명 직접 지정, 전술 변경. 실시간 중계·박스스코어·체력·파울 표시
4. **내 팀** — 선발/후보/엔트리 제외, 선수별 목표 출전시간, 공격 1~3옵션, 계약·피로도 확인
5. **전술 / 훈련** — 팀 기본 전술, 수비 스토퍼·클러치 해결사, 팀·선수별 훈련 초점
6. **일정 · 순위·기록 · 샐러리캡** — 전체 일정과 박스스코어, 플레이오프 대진, 개인 기록 순위, 구단별 보수 현황
7. **비시즌** — 챔피언결정전이 끝나면 열립니다.
   ① 연봉협상·FA 재계약·외국선수 재계약 → ② FA 시장(5일) → ③ 신인 드래프트(자동) → 새 시즌 시작

## 게임 규칙

| 항목 | 내용 |
|---|---|
| 시즌 | 2026-10-03 개막 ~ 2027-04-11, 팀당 54경기. 1~6위 플레이오프: 6강·4강 5전3선승, 챔피언결정전 7전4선승 |
| 외국선수 | 팀당 2명. 1·4쿼터·연장 1명, 2·3쿼터 2명 동시 출전 (라인업 지정 시 검증) |
| 아시아쿼터 | 팀당 1명, 국내선수와 같이 출전 제한 없음 |
| 샐러리캡 | 국내선수 30억(보수 = 연봉 + 인센티브), 최소 소진율 70%, 최저 보수 4,200만 원 |
| 외국선수 연봉 | 2명 합계 100만 달러, 1인 최대 70만 달러 (아시아쿼터는 게임 내 상한 20만 달러) |
| 재계약 | 기존 소속 선수 연봉협상·재계약은 31.5억까지 허용 (30억 초과분 사치세). 외부 FA 영입은 30억 이하만 |
| 연봉협상 | 국내선수는 계약기간 중에도 매 시즌 보수 재협상. 4번 안에 합의 못 하면 재정위원회 보수 조정 (선수 요구액과 구단 제시액 중 공정가치에 가까운 쪽으로 결정) |
| FA 보상 | 직전 시즌 보수 30위 이내 → 보수 100%, 31~40위 → 50%, 41위 이하 → 없음 (2026 개정 규정, 보상금 방식) |
| 등록 인원 | 국내선수 12~18명, 외국선수 1~2명 |

## 선수 능력치와 성장

- **능력치**: 오버롤 / 공격 / 수비 종합치 + 세부 14개(골밑 마무리, 덩크, 미드레인지, 3점, 자유투, 볼핸들링, 패스, 스틸, 블록,
  공·수 리바운드, 파워, 체력, 스피드). KBL 실제 기록을 리그 퍼센타일로 바꿔 50~99로 산정
- **KBL 경험 없는 외국선수**: 해외리그 기록에 리그 강도(NBA 1.0, 중국 CBA 1.05, 일본 B1 0.9, 푸에르토리코 0.8, 대만 0.65 등)를 곱해
  KBL 기준으로 환산한 뒤 같은 방식으로 평가
- **훈련**: 하루 성장치 = 나이(어릴수록 큼) × 잠재력 × 성실성 × 강도. 잠재력은 드래프트 순위·나이·커리어 기록 추세로 산출
- **경험치**: 경기 출전시간과 활약만큼 쌓이고(플레이오프 1.5배), 레벨업 때 포지션·강점에 맞는 능력치 상승
- **노화**: 30세 이상은 매일 스피드·체력·덩크·파워 등 운동능력이 조금씩 감소
- **피로·부상**: 출전시간과 훈련 강도만큼 피로가 쌓이고, 피로가 높으면 경기력·성장이 떨어지며 부상 위험이 커짐

## AI 구단

2026-27 실제 감독 기준으로 감독마다 템포·3점 비중·수비 전술·로테이션 깊이·유망주 선호가 다릅니다.

| 구단 | 감독 | 스타일 |
|---|---|---|
| 서울 SK | 전희철 | 속공·트랜지션, 압박 수비 |
| 창원 LG | 조상현 | 조직 수비, 느린 템포 |
| 안양 정관장 | 유도훈 | 수비·지역방어 |
| 고양 소노 | 손창환 | 양궁 농구 |
| 부산 KCC | 이상민 | 스타 중심, 주전 의존 |
| 수원 KT | 문경은 | 모션 오펜스·3점 |
| 울산 현대모비스 | 양동근 | 압박 수비·육성 |
| 대구 한국가스공사 | 강혁 | 런앤건 |
| 원주 DB | 이규섭 | 밸런스 |
| 서울 삼성 | 김상식 | 모션 오펜스 |

AI 출전시간은 선수 오버롤 순위로 정하고(외국선수 1옵션 약 30~34분, 2옵션 나머지), 피로도가 높으면 줄입니다.
비시즌에는 AI 구단도 같은 규칙으로 재계약·FA 영입·외국선수 교체를 합니다.

## 데이터와 추정치

| 데이터 | 기준 |
|---|---|
| 로스터·신상정보·시즌 기록 | KBL 공식 기록 기준 2026-27 로스터 188명, 정규시즌 기록 (`data/processed/`) |
| 2026-27 보수 | 37명은 KBL 선수 등록 결과·FA 계약 보도값 (`source=reported`). 나머지는 구단별 보도된 샐러리캡 소진율과 출전시간·득점·경력으로 추정 (`source=estimated`) |
| FA 년도 | 계약기간이 보도된 선수는 실제 값. 나머지는 드래프트 1라운드 5시즌 / 2라운드 3시즌 규정으로 계산하거나 추정 |
| 일정 | 개막·종료일, 개막전 대진(KCC-LG, 소노-가스공사, 정관장-현대모비스), "평일 1경기·주말 3경기" 원칙은 실제와 같음. 나머지 날짜와 휴식기(FIBA 윈도우·올스타)는 이 원칙에 맞춰 생성 |
| 소프트캡 | 세부 운영 방식이 공개되지 않아 위 "재계약" 규칙으로 구현 |
| 감독 성향 | 감독 명단은 실제, 성향 수치는 알려진 팀 컬러를 참고한 게임용 설정값 |

- 경기 엔진의 슛 분포는 2025-26 실제 개인 득점과의 오차가 가장 작도록 보정했습니다 (팀 평균 약 81점).
- 계약 데이터는 `data/scripts/build_contracts.py`로 다시 만들 수 있고, CSV를 직접 고친 뒤 `npm run seed`로 반영할 수 있습니다.
- 동명이인은 나이 어린 쪽에 `B`를 붙여 구분합니다 (이정현B: 고양 소노, 최승욱B: 대구 한국가스공사).
