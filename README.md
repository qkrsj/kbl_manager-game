# KBL Manager

Football Manager · NBA2K 마이GM 스타일의 **KBL(한국프로농구) 매니저 게임**입니다.
2026-27 시즌부터 시작해 내가 고른 팀의 전술·출전시간·훈련·계약을 직접 관리하고,
나머지 9개 팀은 실제 감독 성향에 따라 AI가 운영합니다.

## 설치와 실행 (처음 하는 분 기준)

### 1. 설치할 프로그램 3개

| 프로그램 | 받는 곳 | 설치할 때 주의할 점 |
|---|---|---|
| **Node.js** (LTS, 22 이상) | https://nodejs.org → 왼쪽 "LTS" 버튼 | 기본값 그대로 "Next"만 누르면 됨 |
| **PostgreSQL 16** | https://www.postgresql.org/download/ → 운영체제 선택 → "Download the installer" | ⚠️ 중간에 **`postgres` 계정 비밀번호**를 정하라고 나옴 → **꼭 기억하기** (설치 스크립트가 한 번 물어봄). 포트는 기본값 `5432` 그대로 |
| **Git** (선택) | https://git-scm.com/downloads | 코드를 `git clone`으로 받을 때만 필요. 없으면 GitHub에서 ZIP으로 받아도 됨 |

- **macOS**는 Homebrew가 있다면 터미널에서 `brew install node postgresql@16` 후 `brew services start postgresql@16`
  (이 경우 `postgres` 계정 대신 **내 Mac 사용자 이름**이 관리자 계정이고 비밀번호가 없습니다 → 아래 2단계에서
  `PGADMIN_USER=내사용자이름 npm run setup` 으로 실행하고 비밀번호 질문에는 그냥 Enter)
- 설치가 끝났는지 확인: 터미널(Windows는 **명령 프롬프트** 또는 **PowerShell**)에서
  ```
  node -v      # v22.x.x 처럼 나오면 OK
  npm -v
  ```

### 2. 게임 받고 최초 설치 (한 번만)

```bash
# 원하는 폴더에서 (ZIP으로 받았다면 압축 푼 폴더로 이동만 하면 됨)
git clone https://github.com/qkrsj/kbl_manager-game.git
cd kbl_manager-game

npm run setup
```

`npm run setup`이 자동으로 하는 일:
1. 서버·웹·DB 패키지 설치 (처음엔 몇 분 걸림)
2. **PostgreSQL `postgres` 계정 비밀번호를 물어봄** → 1단계에서 정한 비밀번호 입력
3. 게임 전용 DB 계정(`kbl_app`)과 DB(`kbl_manager`) 생성, 테이블 생성
4. 2026-27 시즌 새 게임 데이터 생성

마지막에 `✅ 설치 완료!`가 나오면 성공입니다.

### 3. 게임 실행 (할 때마다)

```bash
cd kbl_manager-game     # 게임 폴더에서
npm start
```

- 터미널에 `[서버] ... listening on port 4000`, `[웹] ... http://localhost:5173` 이 보이면
  **브라우저에서 http://localhost:5173** 을 엽니다.
- 끌 때는 그 터미널에서 **Ctrl + C**. 진행 상황은 DB에 저장되어 있어 다시 `npm start` 하면 이어서 할 수 있습니다.
- 로딩 화면 다음 메인 화면에서 **새로 시작** → 감독 프로필을 만들고 팀을 고르면 그 팀의 감독으로 부임합니다.
  다음부터는 **이어서 하기**로 저장된 게임을 계속합니다. 화면·로딩 관련 설정은 오른쪽 위 **⚙ 설정**에 있습니다.

### 그 밖의 명령 (게임 폴더에서)

| 명령 | 설명 |
|---|---|
| `npm run setup` | 최초 설치 (다시 실행해도 안전하지만, 마지막 단계에서 **세이브가 초기화**됨) |
| `npm start` | 게임 실행 (서버 + 웹) |
| `npm run new-game` | 세이브 초기화 후 새 게임 (감독 프로필 없이 기본 팀으로 — 보통은 화면의 **새로 시작**을 쓰세요) |
| `npm run simulate` | 한 시즌 → 플레이오프 → 비시즌 → 다음 시즌 시작까지 자동 진행해 결과 출력 (⚠️ 세이브 초기화됨, 검증용) |

### 문제가 생기면

| 증상 | 해결 |
|---|---|
| `'npm'은(는) 내부 또는 외부 명령...이 아닙니다` | Node.js 설치 후 **터미널을 새로 열기**. 그래도 안 되면 PC 재시작 |
| `PostgreSQL 접속 실패: password authentication failed` | `postgres` 비밀번호가 틀림. PostgreSQL 설치 때 정한 비밀번호 확인 |
| `PostgreSQL 접속 실패: connect ECONNREFUSED` | PostgreSQL이 꺼져 있음. Windows: 시작 메뉴 → "서비스" → `postgresql-x64-16` 시작 / macOS(brew): `brew services start postgresql@16` |
| 화면에 "세이브 데이터를 불러올 수 없습니다" | `npm start`를 한 터미널에 `[서버] ... listening on port 4000` 이 떴는지 확인 |
| `port 4000(또는 5173) is already in use` | 이미 다른 터미널에서 게임이 켜져 있음. 그 터미널에서 Ctrl + C 후 다시 실행 |
| PostgreSQL 포트가 5432가 아님 | `PGPORT=5433 npm run setup`, `PGPORT=5433 npm start` 처럼 포트를 지정 (Windows PowerShell: `$env:PGPORT=5433; npm start`) |

### 개발자용 (수동 실행)

설치 스크립트 없이 직접 하려면: DB 접속 기본값은 `kbl_app` / `devpassword` @ `localhost:5432` / `kbl_manager`
(`PGHOST`, `PGPORT`, `PGUSER`, `PGPASSWORD`, `PGDATABASE` 환경변수로 변경).

```bash
cd packages/db   && npm install && DATABASE_URL=postgres://kbl_app:devpassword@localhost:5432/kbl_manager npm run migrate:up
cd apps/server   && npm install && npm run seed && npm run dev    # API http://localhost:4000 (파일 수정 시 자동 재시작)
cd apps/web      && npm install && npm run dev                    # 웹 http://localhost:5173
```
`apps/server`에서 `npm run typecheck`(타입 검사), `npm run simulate -- --live`(직접 지휘 모드로 시뮬레이션),
`npm run simulate -- --stop-at-offseason`(비시즌 시작 직후에서 멈춤)도 쓸 수 있습니다.

## 게임 방법

1. **메인 화면** — 표지 사진 위에 왼쪽 **이어서 하기 / 새로 시작**, 오른쪽 **설정**(테마·글자 크기·로딩 화면·화면 효과 등)
2. **새로 시작** — ① 감독 프로필: 이름·나이·출신·좌우명, **플레이 스타일**(시작 전술), **성격**·**운영 방향**(선수단 성장 보너스)
   ② 팀 선택: 팀별 전력과 **핵심 선수 2명**을 보고 고르면 그 팀의 기존 감독 자리를 내가 맡습니다
3. **홈(허브)** — 팀 배너(성적·순위·다음 경기), 내 팀·순위·일정·훈련·다른 팀 전력·개인 기록·감독실·샐러리캡·리그 소식 타일. 타일을 누르면 해당 메뉴로 이동
4. **상단 메뉴** — 내 팀(개요·로스터/출전시간·전술·연봉) / 다른 팀(전력 카드, 우리 팀과 비교) / 트레이드 /
   순위·기록(팀 순위·개인 기록·팀 기록·플레이오프) / 훈련 / 달력·일정 / 감독실(프로필 수정·통산 성적)
5. **달력** — 한 달 달력에 우리 팀 경기(상대·홈/원정·승패·점수)와 오늘, 리그 휴식기가 표시됩니다.
   - 오늘 아래 카드에서 하루씩 진행: **경기일**은 상대 전력을 보고 게임플랜을 정한 뒤 **경기 직접 지휘** 또는 **빠른 시뮬레이션**,
     **경기 없는 날**은 휴식 또는 훈련
   - 미래 날짜를 누르고 **이 날까지 진행** → 저장된 훈련 계획으로 한 번에 진행 (중간에 우리 팀 경기일이 오면 그날 멈춤)
   - 지난 경기를 누르면 박스스코어
6. **경기 직접 지휘 (실시간 중계)** — 코트 그림 위에서 공격·수비가 한 동작씩(패스·슛·리바운드·스틸) 진행되고, 아래에 문자 중계가 쌓입니다.
   - 속도 1x/2x/4x, 일시정지, **쿼터 스킵**, **경기 스킵**
   - **작전타임**: 코트 위 5명 교체(바로 반영), 템포·3점 비중·수비·더블팀·리바운드 강조 변경. 쿼터가 끝날 때마다 잠시 멈춤
7. **훈련** — 팀 전체(방식·초점·강도)를 한 번에 정하거나, 선수마다 방식(훈련/휴식)·초점·강도를 따로 지정. 여러 명을 골라 한 번에 바꿀 수도 있음
8. **출전시간** — 선발 / 후보 / 엔트리 제외로 나눠 보여주고, 슬라이더로 분 단위 조절. 합계 200분·외국선수 60분·선발 포지션 구성을 위에서 바로 확인
9. **공격 옵션** — 전술 탭에서 1·2·3옵션을 지정하면 그 선수 위주로 공격합니다 (1옵션 20점 안팎, 2옵션 10점대 중후반, 3옵션 10점 안팎 정도로 차등).
   AI 팀은 공격 능력치·득점력 순으로 자동 지정
10. **트레이드** — 상대 팀을 고르고 보낼 선수·받을 선수를 체크하면 양 팀 평가가 바로 보입니다.
    - 팀 상황(우승 경쟁·중위권·리빌딩)에 따라 지금 실력과 잠재력·나이를 보는 비중이 다르고, 주전급이 부족한 포지션 선수는 더 높게 봅니다
    - **양 팀 모두 이득(윈윈)**이어야 성사: 상대는 +3% 이상 이득, 우리 팀은 5% 넘게 손해 보지 않아야 함. 간판 선수는 확실한 이득(+10%) 없이는 안 내줌
    - 규정: 국내 12~18명, 외국선수 2명·아시아쿼터 1명 이하, 국내 보수 31.5억 이하. 마감은 4라운드 종료일(비시즌엔 FA 기간 제외 가능)
    - "이 선수를 받으려면?"으로 상대가 받아들일 만한 우리 선수 조합을 찾아줌. AI 팀끼리 트레이드는 한 시즌 많아야 1건
11. **비시즌** — 챔피언결정전이 끝나면 상단 메뉴에 나타납니다.
   ① 연봉협상·FA 재계약·외국선수 재계약 → ② FA 시장(5일) → ③ 신인 드래프트(자동) → 새 시즌 시작

### 감독 프로필 효과 (내 팀 선수에게만)

| 구분 | 선택지 → 효과 |
|---|---|
| 플레이 스타일 | 속공·트랜지션 / 양궁 농구 / 질식 수비 / 골밑 장악 / 밸런스 → 시작 전술(템포·3점·수비·리바운드). 전술은 언제든 변경 가능 |
| 성격 | 카리스마형 리더 경기 경험치 +15% · 덕장 피로 회복 +20% · 지장 훈련 성장 +10% · 원칙주의자 부상 위험 −25% |
| 운영 방향 | 윈나우 27세 이상 훈련 성장 +15% · 균형 전원 +5% · 리빌딩 24세 이하 +25% |

## 게임 규칙

| 항목 | 내용 |
|---|---|
| 시즌 | 2026-10-03 개막 ~ 2027-04-11, 팀당 54경기. 1~6위 플레이오프: 6강·4강 5전3선승, 챔피언결정전 7전4선승 |
| 외국선수 | 팀당 2명. 1·4쿼터·연장 1명, 2·3쿼터 2명 동시 출전 (라인업 지정 시 검증) |
| 아시아쿼터 | 팀당 1명, 국내선수와 같이 출전 제한 없음 |
| 샐러리캡 | 국내선수 30억(보수 = 연봉 + 인센티브), 최소 소진율 70%, 최저 보수 4,200만 원 |
| 외국선수 연봉 | 2명 합계 100만 달러, 1인 최대 70만 달러 (아시아쿼터는 게임 내 상한 20만 달러) |
| 재계약 | 기존 소속 선수 연봉협상·재계약은 31.5억까지 허용 (30억 초과분 사치세). 외부 FA 영입은 30억 이하만 |
| 연봉협상 | 국내선수는 계약기간 중에도 매 시즌 보수 재협상. 4번 안에 합의 못 하면 재정위원회 보수 조정 (선수 요구액과 구단 제시액 중 공정가치에 가까운 쪽으로 결정) |
| FA 보상 | 직전 시즌 보수 30위 이내 → 보수 100%, 31~40위 → 50%, 41위 이하 → 없음 (2026 개정 규정, 보상금 방식) |
| 등록 인원 | 국내선수 12~18명, 외국선수 1~2명 |

## 선수 능력치와 성장

자세한 산정 방식은 **[docs/능력치산정방식.md](docs/능력치산정방식.md)**에 정리되어 있습니다. 요약:

1. **최근 3시즌 가중 합산** (최근 1.0 / 0.5 / 0.25 × 출전경기수) — 1경기·부상 시즌에 휘둘리지 않음
2. **세부 능력치 14개**를 리그 순위로 산출, 출전시간이 적은 선수는 표본 신뢰도만큼만 인정
3. **오버롤 수준 보정**: 기록 30% + 역할·생산성(출전시간·공헌도, 전성기 실적) 30% + 2026-27 연봉 40%
   (31세 이상은 연봉 45% — 고연봉 베테랑이 나이로 과소평가되지 않게 / 보도되지 않은 추정 연봉은 비중 1/3)
4. **수동 조정**: `data/manual/rating_overrides.csv` (예: 변준형 89)

- **해외리그 기록으로 평가하는 선수** (KBL 첫 시즌, 또는 마지막 KBL 시즌이 5년 이상 지난 선수): 최근 3년 해외 기록을 리그 수준(KBL 1.00, 일본 B1 1.10, 중국 CBA 0.90, 푸에르토리코 BSN 0.85 등)으로 KBL 기준 환산 → 최근 시즌일수록 크게(1.0 / 0.5 / 0.25) 합산 → 빈 항목은 본인 다른 시즌, 없으면 같은 포지션 KBL 선수 중앙값으로 채워 KBL 선수와 같은 방식으로 평가
- **훈련**: 하루 성장치 = 나이 × 잠재력(드래프트 순위·나이·기록 추세) × 성실성 × 강도
- **경험치**: 경기 출전시간과 활약만큼 쌓이고 레벨업 때 포지션·강점에 맞는 능력치 상승
- **노화**: 32세부터 운동능력만 완만하게 감소 (35세 기준 시즌당 항목별 약 −1.7)
- **피로·부상**: 출전시간과 훈련 강도만큼 피로가 쌓이고, 피로가 높으면 경기력·성장이 떨어지며 부상 위험 증가

AI 출전시간은 선수 오버롤 순위로 정하고(외국선수 1옵션 약 30~34분, 2옵션 나머지), 피로도가 높으면 줄입니다.
비시즌에는 AI 구단도 같은 규칙으로 재계약·FA 영입·외국선수 교체를 합니다.

## 데이터와 추정치

| 데이터 | 기준 |
|---|---|
| 로스터·신상정보·시즌 기록 | KBL 공식 기록 기준 2026-27 로스터 188명, 정규시즌 기록 (`data/processed/`) |
| 2026-27 보수 | 37명은 KBL 선수 등록 결과·FA 계약 보도값 (`source=reported`). 나머지는 구단별 보도된 샐러리캡 소진율과 출전시간·득점·경력으로 추정 (`source=estimated`) |
| FA 년도 | 계약기간이 보도된 선수는 실제 값. 나머지는 드래프트 1라운드 5시즌 / 2라운드 3시즌 규정으로 계산하거나 추정 |
| 일정 | 개막·종료일, 개막전 대진(KCC-LG, 소노-가스공사, 정관장-현대모비스), "평일 1경기·주말 3경기" 원칙은 실제와 같음. 나머지 날짜와 휴식기(FIBA 윈도우·올스타)는 이 원칙에 맞춰 생성 |
| 소프트캡 | 세부 운영 방식이 공개되지 않아 위 "재계약" 규칙으로 구현 |
| 감독 성향 | 감독 명단은 실제, 성향 수치는 알려진 팀 컬러를 참고한 게임용 설정값 |

- 경기 엔진의 슛 분포는 2025-26 실제 개인 득점과의 오차가 가장 작도록 보정했습니다 (팀 평균 약 81점).
- 계약 데이터는 `data/scripts/build_contracts.py`로 다시 만들 수 있고, CSV를 직접 고친 뒤 `npm run seed`로 반영할 수 있습니다.
- 동명이인은 나이 어린 쪽에 `B`를 붙여 구분합니다 (이정현B: 고양 소노, 최승욱B: 대구 한국가스공사).
