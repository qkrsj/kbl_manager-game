# KBL Manager — KBL 매니저 게임

Football Manager · NBA2K 마이GM 스타일의 KBL(한국프로농구) 매니지먼트 게임입니다.
**2026-27 시즌**부터 시작해 내가 고른 팀의 전술·출전시간·훈련·계약을 직접 관리하고, 나머지 9개 팀은
실제 감독 성향에 따라 AI가 운영합니다.

## 실행 방법

```bash
# 0) PostgreSQL 준비 (기본 접속: kbl_app / devpassword @ localhost:5432 / kbl_manager — PG* 환경변수로 변경 가능)
# 1) DB 마이그레이션
cd packages/db && npm install && DATABASE_URL=postgres://kbl_app:devpassword@localhost:5432/kbl_manager npm run migrate:up
# 2) API 서버
cd apps/server && npm install && npm run seed && npm start      # http://localhost:4000
# 3) 웹
cd apps/web && npm install && npm run dev                       # http://localhost:5173
```
게임 안의 **🔄 새 게임** 메뉴에서 팀을 고르면 세이브가 초기화되고 2026-27 시즌이 새로 시작됩니다.
`npm run simulate`(apps/server)는 API와 같은 로직으로 한 시즌 전체 + 비시즌 + 다음 시즌 시작까지 자동 진행해 검증합니다.

## 게임 기능

| 영역 | 내용 |
|---|---|

| 하루 단위 진행 | 한 번에 하루씩. **경기일**: 게임플랜(템포·3점 비중·수비 전술·상대 에이스 더블팀·리바운드 강조) 설정 후 *직접 지휘* 또는 *빠른 시뮬*. **경기 없는 날**: 휴식 또는 훈련(초점 7종 × 강도 3단계) |
| 경기 직접 지휘 | 5분 구간마다 작전타임: 코트 위 5명 직접 지정, 템포/3점/수비 전술/더블팀 변경, 실시간 중계·박스스코어·선수 체력·파울 표시 |

| 능력치 | 오버롤/공격/수비 종합 + 14개 세부 능력치. KBL 기록 기반 퍼센타일 변환, KBL 경험 없는 외국선수는 해외리그 기록 × 리그 강도(NBA 1.0, CBA 1.05, B1 0.9 …)로 환산 |
| 성장·하락 | 훈련(나이·잠재력[드래프트 순위·나이·기록 추세]·성실성·강도 반영), 경기 경험치 레벨업, 30세 이상 노화, 피로도, 부상 |
| AI 9개 팀 | 실제 2026-27 감독(전희철·조상현·유도훈·손창환·이상민·문경은·양동근·강혁·이규섭·김상식)별 템포/3점/수비 전술·로테이션 깊이·유망주 선호. 출전시간은 오버롤 기반 뎁스차트 |
| 계약·샐러리캡 | 2026-27 보수, FA 년도. 국내 캡 30억(최소 70%), 외국선수 2명 합계 $100만·1인 $70만, 최저 4,200만 |
| 비시즌 | ① 연봉협상(4회 결렬 시 KBL 재정위원회 보수 조정) + FA 원소속 구단 재계약 + 외국선수 재계약 → ② FA 시장(5일, AI 구단과 경쟁, 보상금 규정) + 외국선수 시장 → ③ 자동 신인 드래프트 → 새 시즌(비시즌 성장·노화·은퇴, 새 일정) |
| 시즌 | 2026-10-03 개막 ~ 2027-04-11, 팀당 54경기, 6강(5전3선)·4강(5전3선)·챔프전(7전4선) |

## 데이터 출처와 추정치 (중요)

- **2026-27 보수** (`data/processed/contracts_2026_27.csv`, 생성 스크립트 `data/scripts/build_contracts.py`)
  - `source=reported`: 2026-27 KBL 선수 등록 결과·FA 계약 보도로 확인한 값 — 변준형·허훈 8억, 안영준·양홍석 7억5천,
    이정현(소노) 7억2천, 강상재·이승현 6억5천 등 구단별 보수 상위 선수, 조한진·박준영·서민수·정효근·오세근·최원혁 FA 계약,
    이관희(재정위원회 3억2천), 김동현(조정 7,500만) 등 37명
  - `source=estimated`: 보도로 확인할 수 없는 선수 — 구단별로 보도된 샐러리캡 소진율(소노 98.2%, KCC 97.0%, LG 90.4%,
    DB 86.1%, 현대모비스 84.3%, 가스공사 75.0% 등)에서 확인된 보수를 뺀 잔여액을 최근 시즌 출전시간·득점·경력 비례로 배분.
    2025 신인은 지명순위별 신인 보수 테이블. 외국선수·아시아쿼터 연봉은 옵션(1/2옵션) 기준 추정
  - FA 년도: 보도된 계약기간이 있으면 그 값, 없으면 드래프트 1라운드 5시즌/2라운드 3시즌 규정으로 계산,
    이미 첫 FA를 지난 선수는 1~4년 잔여로 추정
- **일정**: 개막·종료일, 개막일 대진(KCC-LG, 소노-가스공사, 정관장-현대모비스), "평일 1경기·주말 3경기" 원칙은 실제와 같고,
  나머지 대진 날짜는 이 원칙과 FIBA 휴식기·올스타 브레이크(추정 날짜)에 맞춰 생성 (전체 경기표는 확인 불가)
- **샐러리캡 소프트캡**: 2026-27 "소프트캡" 보도만 확인 가능해, 게임에서는 외부 영입 30억 하드캡 / 기존 선수 재계약 31.5억까지 허용(초과분 사치세)으로 구현
- **감독 성향**: 감독 명단은 실제, 전술 성향 수치는 알려진 팀 컬러를 참고한 게임용 설정값
- **엔진 보정**: 슛 결정 곡선은 2025-26 실제 개인 득점과의 평균오차가 최소가 되도록 보정 (시즌 평균 팀 득점 약 81점)

## 데이터 폴더 구조

```
data/
├── raw/               # 팀별 원본 엑셀 (10개 구단, 팀당 시트 1개 = 선수 1명, 시즌별 정규시즌 기록)
│   └── (10개 팀 xlsx)
├── processed/          # 정제·통합된 핵심 데이터
│   ├── roster.csv                  # 193명 로스터 (등번호/포지션/신장/체중/국적) — 2026-27 시즌 기준
│   ├── kbl_시즌기록_master.csv     # 선수×시즌 단위 원시 스탯 (939행, 정규시즌만)
│   ├── kbl_선수목록.csv            # 188명 전체 명단 + 시즌기록 보유 여부
│   ├── contracts_2026_27.csv       # 2026-27 보수/FA 년도 (source: reported/estimated)
│   └── KBL_시즌기록_통합.xlsx      # 위 시즌기록+선수목록 CSV를 시트로 합친 엑셀본
├── scripts/build_contracts.py  # 2026-27 계약 데이터 생성 (보도값 + 추정 규칙)
└── manual/              # 스탯만으로 산출 불가능한 수동 추정치
    └── foreign_player_attribute_estimates.csv   # KBL 데뷔 시즌 외국인 7명, 해외리그 경력 기반 정성 추정 능력치
```

## 데이터 범위

- KBL 10개 구단 전체 로스터, **정규시즌 기록만** (플레이오프·챔피언결정전 제외)
- 선수당 커리어 전체 시즌 (통산 평균 행은 제외하고 시즌별로 분리)
- `roster.csv`는 189명(국내+외국인 전원, 시즌기록 파일과 완전히 정합됨), `kbl_시즌기록_master.csv`는
  174명 기록 보유 (14명은 신인/이번 시즌 KBL 데뷔 외국인 등으로 기록 없음)

| 컬럼 | 의미 | 컬럼 | 의미 |

| PTS | 총 득점 | STL | 스틸 |
| 2PM/2PA/2P% | 2점슛 성공/시도/성공률 | BLK | 블록 |
| 3PM/3PA/3P% | 3점슛 성공/시도/성공률 | GD | 굿디펜스 |
| FGM/FGA/FG% | 야투(2점+3점 합산) 성공/시도/성공률 | DK/DKA | 덩크 성공/시도 |
| FTM/FTA/FT% | 자유투 성공/시도/성공률 | TO | 턴오버 |
| OREB/DREB | 공격/수비 리바운드 | PF | 개인파울 |

## 데이터 정제 이력 (Changelog)

### 1차 — 시즌기록 통합 (10개 팀 엑셀 → 마스터 CSV)
- Min(출장시간) 컬럼 버그 수정: 엑셀이 "MM:SS"를 "H:MM"으로 오인식해 저장된 값을
  1,113개 셀 전수 검증 후 자동 복구 (`MIN_표시`, `MIN_분(소수)` 컬럼 분리).
- 동명이인 2쌍 발견 및 구분: 나이 어린 쪽에 `B` 접미사 부여.
  - `이정현` → 원주 DB(1987년생, 원본 유지) / 고양 소노(1999년생) → **이정현B**
  - `최승욱` → 고양 소노(1993년생, 원본 유지) / 대구 한국가스공사(1994년생) → **최승욱B**
- `당시소속팀` 컬럼 띄어쓰기 정규화 (예: `울산현대모비스` → `울산 현대모비스`).
  단, 실제 구단 개명·전신 이력(`안양 KGC`↔`안양 정관장`, `원주 동부`↔`원주 DB`,
  `울산 모비스`↔`울산 현대모비스`, `인천 전자랜드`/`대구 오리온스` 등)은 보존.

### 2차 — roster.csv를 시즌기록 기준으로 재정합
과거 세션에서 만든 `roster.csv`(9월 3일자, 신상정보)와 이번 시즌기록 파일 간
선수 명단을 전수 대조하여 **시즌기록 쪽을 진실로 간주**하고 roster.csv를 아래와 같이 수정:

- **표기 통일**: 조니 오브라이언트(구 "자니"), 프레디(구 "프레디 무티바"),
  이정현B / 최승욱B (동명이인 접미사 반영)
- **소속 정정**: 이대헌 — 울산 현대모비스 → **안양 정관장** (트레이드 반영, roster.csv가 구버전이었음)
- **부산 KCC 외국인 교체 반영 + 신체정보 보완**: 루이스 킹 (201cm/92kg, 스몰 포워드, 2026-27 신규 영입).
  KBL 기록이 없는 신규 외국인이므로 `manual/foreign_player_attribute_estimates.csv`에도
  해외리그(NBA/중국 CBA/푸에르토리코) 경력 기반 추정 능력치를 추가함 (총 7명).

- **국적 표기**: 프레디(서울 SK)는 여권상 콩고민주공화국 국적이나, KBL 규정상 외국인 쿼터가 아닌
  국내 선수 드래프트로 입단(2024년 개정 규정: 한국농구협회 5년 이상 등록 외국 국적자는 국내 드래프트 지원 가능)
  했으므로 외국인 쿼터 구분 목적의 `nationality` 컬럼은 **KOR**로 표기함.
