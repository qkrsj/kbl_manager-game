## 폴더 구조
- `roster.csv` — 10개 구단 전체 로스터 189명 (이름, 등번호, 포지션, 신체조건, 국적) — 2026-27 시즌 기준, ✅완료
- `season_stats.csv` — 선수 시즌별 박스스코어 기록 — 헤더만 있음, 데이터 0건 (국내 159명 + KBL경력 용병 24명 전부 미수집)
- `foreign_player_attribute_estimates.csv` — 순수 첫 시즌 용병 6명의 타 리그 경력 기반 추정 능력치 (신뢰도 태그 포함) — ✅완료
