# KBL Manager — 스탯 → 능력치 변환 규칙표 (v0.5)

> 자동 도출 확정 항목 정리. 보류/수동조정 항목은 별도 표기.
> 퍼센타일 정규화 기준: **전체 리그(174명) 기준**
> 실측 검증 완료 (2025-26 시즌 등 최신 데이터 기준)

---

## 1. 공격 (Offensive)

### `finishing` — 골밑 득점력 (볼륨 단독)
```
finishing = 경기당PPA(페인트존 시도횟수) 퍼센타일
```
> 정확도(PP%)는 포함하지 않음. 실측 검증 결과 KBL 데이터상 고볼륨 선수의 PP%가
> 극단적으로 낮은 케이스가 없어 정확도를 빼도 왜곡 위험이 낮다고 판단.

### `dunking` — 덩크 (finishing에서 분리된 신설 속성)
```
dunking = 시즌환산 DKA(덩크 시도 횟수) 퍼센타일
```

### `midRangeShooting` — 미드레인지 슈팅
```
미드성공 = 2PM - PP, 미드시도 = 2PA - PPA
보정된미드% = 시즌환산 베이지안보정 (k=20)

midRangeShooting = 보정된미드% 퍼센타일 × 0.7 + 경기당미드시도 퍼센타일 × 0.3
```

### `threePointShooting` — 3점 슈팅
```
보정3P% = 시즌환산 베이지안보정 (k=20)

threePointShooting = 보정3P% 퍼센타일 × 0.7 + 경기당3PA 퍼센타일 × 0.3
```

### `freeThrowShooting` — 자유투
```
보정FT% = 시즌환산 베이지안보정 (k=15)

freeThrowShooting = 보정FT% 퍼센타일 × 0.85 + 경기당FTA 퍼센타일 × 0.15
```

### `ballHandling` — 드리블/볼 핸들링
```
usage = FGA + 0.44×FTA + TO (시즌환산)
correctedToRatio = 베이지안보정(TO/usage, 이벤트기반 동적k)
correctedAstPerUsage = 베이지안보정(AST/usage, 이벤트기반 동적k)

ballHandling = (1 - correctedToRatio 퍼센타일) × 0.4 + correctedAstPerUsage 퍼센타일 × 0.6
```

### `passing` — 패스/어시스트 창출력
```
correctedAST = 시즌환산 분당AST, 베이지안보정(이벤트기반 동적k, 목표 5개사건)

passing = correctedAST 퍼센타일
```

### `postScoring`
> ❌ **삭제 확정** (finishing이 볼륨 중심으로 재정의되며 흡수)

## 2. 수비 (Defensive)

### `steal`
```
correctedSTL = 시즌환산 분당STL, 베이지안보정(이벤트기반 동적k)
correctedGD = 시즌환산 분당GD(굿디펜스), 베이지안보정(이벤트기반 동적k)

steal = correctedSTL 퍼센타일 × 0.85 + correctedGD 퍼센타일 × 0.15
```
> GD 보너스는 steal에만 적용. shotBlocking/defensiveRebounding은 빅맨 편향 속성인데
> GD는 가드 편향 스탯이라 함께 블렌딩하면 역효과 (실측 검증 중 발견, 제외 확정).

### `shotBlocking`
```
correctedBLK = 시즌환산 분당BLK, 베이지안보정(이벤트기반 동적k)
shotBlocking = correctedBLK 퍼센타일
```

### `defensiveRebounding`
```
correctedDREB = 시즌환산 분당DREB, 베이지안보정(이벤트기반 동적k)
defensiveRebounding = correctedDREB 퍼센타일
```

### `offensiveRebounding` (신설, defensiveRebounding과 동일 방식)
```
correctedOREB = 시즌환산 분당OREB, 베이지안보정(이벤트기반 동적k)
offensiveRebounding = correctedOREB 퍼센타일
```

### `perimeterDefense` / `postDefense`
> ❌ **삭제 확정** (GD 컬럼 재료 겹침 문제로 독립 속성화 포기)

## 3. 신체/정신 (Physical/Mental)

### `stamina`
```
stamina = 경기당 Min(출장시간) 퍼센타일 (거친 근사치)
```

### `injuryProneness`
```
출장률(시즌별) = 그시즌 G / 그시즌 리그최대G
최근3시즌 평균 출장률 계산 (보유시즌 3개 미만이면 중립값 50)

injuryProneness = 100 - 평균출장률 퍼센타일
```
> 한계: 결장 사유가 부상/방출/코칭스태프 판단인지 구분 불가. 근사치.

### `strength` (거친 초기값, 키/몸무게 기반)
```
strength = 몸무게 퍼센타일 (단독)
```

### `speed` (거친 초기값, 키/몸무게 기반)
```
speed = 100 - (키 퍼센타일×0.5 + 몸무게 퍼센타일×0.5)
```

### `consistency`, `clutch`
> ⏸ **수동 조정** (경기별 로그 데이터 필요, 향후 작업)

## 4. 성장 (Growth-related)

### `potential` — 성장 잠재력
```
potential = 나이점수×0.45 + 드래프트점수×0.25 + 추세점수×0.30
(용병/귀화 선수는 국적 기준으로 계산 자체를 제외 → null)
```

**① 나이점수** (연속함수)
```
나이 ≤ 23           → 100
23 < 나이 < 30       → 100 × exp(-0.08×(나이-23))
나이 ≥ 30           → 61.9 × exp(-0.15×(나이-29))
```

**② 드래프트점수** (전체순번 기반 연속함수, v0.5로 개편)
```
overallPick = (라운드-1)×10 + 라운드내순위

1순위: 100 (고정)
2~4순위: 100 × exp(-0.025×(pick-1))
5~10순위: [4순위값] × exp(-0.04×(pick-4))
11~20순위: [10순위값] × 0.9 × exp(-0.035×(pick-10))
21순위 이상: [20순위값] × exp(-0.09×(pick-20))

특수 케이스:
  연고선수 출신 → 100
  귀화/해외 출신 → potential 계산 자체 제외 (null)
  순수 언드래프트 → 15
```

**③ 추세점수** (군공백 등 결측 시즌 대응, 신인도 처리 가능)
```
종합효율 = PTS+REB+AST+STL+BLK-TO

유효시즌 3개 이상 → 선형회귀 기울기 퍼센타일
유효시즌 2개 → (최신-이전) 차이값 퍼센타일
유효시즌 1개 (신인) → 그 시즌 종합효율을 "1시즌 선수 집단" 내에서 퍼센타일 비교
유효시즌 0개 → 중립값 50
```

**현재 데이터 현황**: 국내선수 151명 실제 나이/드래프트 반영 완료. 용병 23명은 계산 제외(null).

### `workEthic`, `injuryProneness`(위 항목과 중복 아님, workEthic만)
> ⏸ **workEthic은 수동 조정** (데이터로 도출 불가)
