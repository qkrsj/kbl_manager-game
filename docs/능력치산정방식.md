# 능력치 산정 방식 (v1.0)

게임 시작(새 게임) 때 모든 선수의 능력치는 아래 4단계로 정해집니다.

```
[1] 최근 3시즌 기록 합산 → [2] 세부 능력치(유형) 산출 → [3] 역할·생산성·연봉으로 수준 보정 → [4] 수동 조정
```

## 1단계 — 최근 3시즌 가중 합산

한 시즌만 보면 "1경기만 뛴 선수"나 "부상으로 반 시즌 뛴 에이스"가 크게 왜곡되기 때문에,
**최근 3시즌을 합쳐서** 하나의 합성 시즌으로 봅니다.

| 시즌 | 가중치 |
|---|---|
| 가장 최근 | 1.0 × 출전 경기수 |
| 1년 전 | 0.5 × 출전 경기수 |
| 2년 전 | 0.25 × 출전 경기수 |

경기당 기록은 위 가중치로 평균을 내고, 성공률(%)은 합산한 성공/시도로 다시 계산합니다.
→ 1경기만 뛴 시즌은 가중치가 1밖에 안 되어 거의 영향을 주지 못합니다.
→ 최신 시즌 비중이 커서, 최근 출전이 크게 줄어든 베테랑이 몇 년 전 기록으로 높게 평가되지 않습니다.

## 2단계 — 세부 능력치 (선수 유형)

각 항목을 KBL 전체 선수와 비교한 **순위(퍼센타일)**를 50~99 점수로 바꿉니다.

| 능력치 | 근거 기록 |
|---|---|
| 골밑 마무리 | 경기당 페인트존 시도 |
| 덩크 | 덩크 시도 |
| 미드레인지 | 미드레인지 성공률(표본 보정) 70% + 시도 30% |
| 3점슛 | 3점 성공률(표본 보정) 70% + 시도 30% |
| 자유투 | 자유투 성공률 85% + 시도 15% |
| 볼핸들링 | 볼 관여 대비 턴오버(적을수록↑) 40% + 어시스트 60% |
| 패스 | 분당 어시스트 |
| 스틸 | 분당 스틸 85% + 굿디펜스 15% |
| 블록 / 수비·공격 리바운드 | 분당 블록 / 리바운드 |
| 체력 | 경기당 출전시간 |
| 파워 / 스피드 | 체중 / 키·체중 (체격 기반 추정) |

**표본 신뢰도:** 합산 출전시간이 적으면 순위를 그만큼만 인정하고, 나머지는 "교체 선수 수준"(하위 15%)으로 끌어내립니다.

```
신뢰도 = 합산 출전분 ÷ (합산 출전분 + 200)
최종 순위 = 실제 순위 × 신뢰도 + 15 × (1 − 신뢰도)
```

| 선수 예 | 합산 출전분 | 신뢰도 |
|---|---|---|
| 주전 (30분 × 50경기 + 이전 시즌) | 약 2,500 | 0.93 |
| 식스맨 (15분 × 40경기) | 약 900 | 0.82 |
| 거의 못 뛴 선수 (1경기 16분) | 약 16~100 | 0.07~0.33 |

→ 연차가 쌓였어도 경기를 거의 못 뛰어 기록이 적은 선수는 능력치가 높게 나오지 않습니다.

## 3단계 — 수준 보정: 기록 · 역할 · 연봉

분당 효율만으로는 "팀에서 얼마나 중요한 선수인가"가 드러나지 않습니다(11분 뛰는 백업 빅맨이 27분 뛰는 에이스보다 높게 나오는 문제).
그래서 **오버롤 수준**은 아래 신호를 섞어 정하고, 세부 능력치는 그 수준에 맞게 **같은 폭으로 평행이동**합니다(강점·약점 모양은 유지).

| 신호 | 내용 | 비중 (30세 이하) | 비중 (31세 이상) |
|---|---|---|---|
| 기록 능력치 | 2단계 세부 능력치로 계산한 오버롤의 순위 | 30% | 25% |
| 역할·생산성 | 경기당 출전시간 순위 40% + 경기당 공헌도 순위 60% (신뢰도 반영) | 30% | 30% |
| 연봉 | 2026-27 보수 순위 (구단·시장의 최신 평가) | 40% | 45% |

- **공헌도** = 득점 + 리바운드 + 어시스트 + 스틸 + 블록 − 턴오버 − 야투 실패 − 자유투 실패
- **전성기 실적:** 최근 5시즌 중 20경기 이상 뛴 최고 시즌의 공헌도를 역할·생산성에 30% 반영합니다. 부상이나 군 복무로 최근이 주춤한 검증된 주전을 위한 장치이며, 점수를 올려주기만 하고 깎지는 않습니다.
- **추정 연봉:** 2026-27 보수가 보도로 확인되지 않은 선수는 연봉을 기록·경력으로 추정한 값이라, 다시 크게 반영하면 이중 반영이 됩니다. 그래서 연봉 비중을 **1/3**로 줄이고 나머지를 기록·역할에 나눕니다(벤치 베테랑 과대평가 방지). 보도 연봉 선수 목록은 `data/processed/contracts_2026_27.csv`의 `source=reported`입니다.
- **베테랑:** 31세 이상은 연봉 비중을 높여, 기록이 조금 떨어져도 고연봉 핵심 베테랑(예: 김선형, 이승현, 이정현)이 나이 때문에 과소평가되지 않게 합니다.
- **신인 계약(2025 드래프트):** 연봉이 정해진 테이블이라 연봉 신호를 쓰지 않습니다(기록 50% + 역할 50%).
- **아시아쿼터:** 달러 연봉이라 국내 연봉과 비교하지 않습니다(기록 50% + 역할 50%). 국내선수와 같은 척도로 평가합니다.
- **외국선수:** 외국선수끼리 비교합니다(기록 50% + 역할 50%).
- **KBL 기록이 없는 외국선수·아시아쿼터:** 세부 능력치는 해외리그 기록에 리그 수준(NBA 1.0, 중국 CBA 1.05, 일본 B1 0.9, 불가리아 0.75, 필리핀 0.55 등)을 곱해 환산하고, 역할·생산성은 환산한 득점+리바운드+어시스트를 같은 그룹 KBL 선수들과 비교합니다(불확실성 때문에 85%만 인정).

최종 순위 → 오버롤 변환:

| 구분 | 오버롤 범위 |
|---|---|
| 국내선수·아시아쿼터 | 58 ~ 90 (상위권일수록 촘촘) |
| 외국선수 | 78 ~ 92 |

## 4단계 — 수동 조정

`data/manual/rating_overrides.csv`에 `이름,오버롤,사유`를 적으면 마지막에 그 오버롤로 맞춥니다.
세부 능력치는 같은 폭으로 이동해서, 선수 유형은 그대로 유지됩니다.

```
name,overall,reason
변준형,89,정관장 에이스 (사용자 지정)
```

파일을 고친 뒤 `npm run new-game`(또는 게임 안의 🔄 새 게임)을 실행하면 반영됩니다.

## 오버롤 · 공격 · 수비 계산

포지션마다 세부 능력치 가중치가 다릅니다 (`apps/server/src/ratings.ts`).

| | 공격 비중이 큰 항목 | 수비 비중이 큰 항목 | 공격:수비 |
|---|---|---|---|
| 가드 | 3점, 볼핸들링, 패스 | 스틸, 스피드 | 60 : 40 |
| 포워드 | 골밑, 미드, 3점 | 스틸, 블록, 수비 리바운드, 파워 | 55 : 45 |
| 센터 | 골밑, 덩크, 공격 리바운드 | 블록, 수비 리바운드, 파워 | 50 : 50 |

오버롤 = (공격·수비 가중 평균 75%) + (둘 중 높은 쪽 25%) + 체력 보정 → 한쪽에 특화된 선수(슈터, 림프로텍터)가 평범한 올라운더보다 지나치게 낮게 나오지 않게 합니다.

## 게임 진행 중 변화

| 요인 | 내용 |
|---|---|
| 훈련 | 하루 성장치 = 나이(22세 이하 최고) × 잠재력 × 성실성 × 훈련 강도. 잠재력 = 나이 45% + 드래프트 순위 25% + 커리어 추세 30% |
| 경기 경험치 | 출전시간·활약만큼 쌓이고, 레벨업 때 포지션·강점에 맞는 능력치 +1 (26세 이하 +2개) |
| 노화 | **32세부터**, 운동능력 6종(스피드·체력·덩크·파워·블록·공격 리바운드)만 조금씩 감소. 기술 능력치(슛·패스 등)는 나이로 감소하지 않음. 시즌당 항목별 대략 33세 −0.8, 35세 −1.7, 38세 −3 |
